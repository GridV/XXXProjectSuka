# 📘 README — GameDev Unity Project

## 🧩 О проекте

Unity-проект, построенный вокруг **системы задач**, **эмоций персонажа**, **диалогов** и **ритм-геймплея**.
Основной управляющий скрипт — **StateController**, который переключает состояния персонажа и запускает связанные подсистемы.

Unity: **6.1 (URP, 2D Renderer)**

---

## 🏗 Структура системы

### **1. StateController**

Управляет жизненным циклом персонажа:

```
Idle
→ WaitingForTask
→ ExecutingTask
→ TaskCompleted
→ Ending
```

Функции StateController:

* получает следующую задачу от TaskManager
* запускает эмоции через EmotionController
* выводит текст через UIController
* запускает RhythmController (если задача содержит ритм-паттерн)
* запускает анимационные последовательности
* завершает задачу и показывает кнопку Next

---

### **2. TaskManager**

* хранит очередь задач
* выдаёт следующую задачу
* обновляет показатели engagement (или любой другой прогресс)

---

### **3. TaskData (ScriptableObject)**

Описание одной игровой задачи.

Поля:

* **description** — текст задачи
* **startEmotion / endEmotion** — эмоции
* **animationSequence[]** — последовательность анимаций
* **rhythmPattern** — RhythmPattern для ритм-геймплея
* **engagementReward** — награда

---

### **4. EmotionController**

* управляет эмоциональными состояниями
* использует Animator
* воспроизводит emotion-клипы или переключает стейты

---

### **5. UIController**

* выводит текст
* очищает UI
* показывает/скрывает кнопку Next

---

### **6. RhythmController**

* запускает RhythmPattern
* проигрывает ритм в цикле (корутина)
* оповещает визуализатор RhythmVisualizerUI

---

### **7. RhythmPattern (ScriptableObject)**

Поля:

* **int[] pattern** — последовательность ударов (0/1)
* **float rhythmSpeed** — скорость (BPM или ticks per second)

---

### **8. RhythmVisualizerUI**

(Если присутствует)

* подсвечивает активный шаг ритма
* отображает визуальный тайминг
